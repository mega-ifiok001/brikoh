# Brikoh – All-in-One Business Commerce Platform

**Live Website:** https://brikoh.com/

## Overview

Brikoh is an all-in-one commerce and business management platform designed to help businesses manage their daily operations, sell products online and in physical stores, track inventory, manage customers, and monitor business performance from a centralized dashboard.

The platform brings essential business operations together, eliminating the need for multiple disconnected tools. Businesses can manage their products, process sales, monitor stock, handle customer payments, and operate multiple business locations from one platform.

## Key Features

### 1. Point of Sale (POS)
- Process in-store transactions.
- Support cash, bank transfer, and credit sales.
- Automatically update inventory after sales.
- Generate customer receipts.
- Track daily sales transactions.

### 2. Online Storefront
- Create a public online storefront.
- Display products to potential customers.
- Allow customers to browse products and place orders.
- Support online checkout and payment processing.
- Provide businesses with their own storefront links.

### 3. Inventory Management
- Manage product information and stock quantities.
- Monitor inventory levels.
- Track stock movements.
- Receive low-stock and expiry alerts.
- Maintain accurate stock records.

### 4. Multi-Branch Management
- Manage multiple business locations.
- Track inventory separately for each branch.
- Transfer stock between branches.
- Monitor branch-level business activities.

### 5. Orders & Customer Management
- Manage incoming orders.
- Maintain customer records.
- Track customer purchases.
- Manage invoices and payment history.
- Record partial payments and outstanding balances.

### 6. Wallet & Payouts
- Track funds received from online sales.
- Monitor available wallet balances.
- Request withdrawals to bank accounts.
- View payout and transaction information.

### 7. Reports & Business Analytics
- Monitor business revenue.
- Track expenses.
- Generate profit and loss reports.
- Analyze sales performance.
- Monitor business activity across sales channels.

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Ensure you have the following installed:

- Node.js (LTS recommended)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate into the project directory**

```bash
cd brikoh
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

If the project requires environment variables, create a `.env` file in the project root and configure the required values.

Example:

```env
# Add your actual project environment variables here
```

Never commit secret API keys, database credentials, or payment gateway secrets to GitHub.

**5. Start the development server**

For a Vite React application:

```bash
npm run dev
```

For a Create React App application:

```bash
npm start
```

For a Next.js application:

```bash
npm run dev
```

**6. Open the application**

Use the local development URL displayed in your terminal.

Common defaults:

```text
http://localhost:5173
```

or

```text
http://localhost:3000
```

## Production Build
